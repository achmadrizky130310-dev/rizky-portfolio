RIZKY PORTFOLIO — UPDATE

Cara upload lewat HP Android:
1. Ekstrak ZIP ini.
2. Buka repository GitHub: achmadrizky130310-dev/rizky-portfolio.
3. Hapus/ganti file lama di root repository dengan isi folder rizky-portfolio-final ini.
4. Upload semua file dan folder (index.html, style.css, script.js, profile.jpg, about-photo.jpg, assets).
5. Commit changes ke branch main.
6. Tunggu GitHub Pages memperbarui website.

Website: https://achmadrizky130310-dev.github.io/rizky-portfolio/
Catatan: folder assets harus tetap berada di samping index.html. Jangan upload folder pembungkusnya sebagai subfolder tambahan.
